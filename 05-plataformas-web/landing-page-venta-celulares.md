# Landing page para venta de celulares

**Categoría:** [Plataformas web](README.md) · **Tecnologías:** HTML, CSS, JavaScript

Landing page moderna y orientada a conversión para una tienda de celulares en Colombia.

## Prompt

```text
Actúa como un desarrollador web senior y diseñador UI/UX experto en e-commerce. Quiero que crees una landing page moderna, atractiva y profesional para la venta de celulares en Colombia.

OBJETIVO
Diseñar una landing page enfocada en conversión, confianza y facilidad de compra, orientada a usuarios que desean comprar celulares de diferentes gamas. La página debe verse elegante, moderna, rápida y optimizada para escritorio y móviles.

REQUERIMIENTOS GENERALES
- Crear una landing page completa para venta de celulares.
- El diseño debe ser limpio, moderno, tecnológico y comercial.
- Debe transmitir confianza, seguridad y sensación de tienda real.
- Debe estar completamente en español.
- Debe estar pensada para el mercado colombiano.
- Los precios deben mostrarse en pesos colombianos (COP), por ejemplo: $1.299.900 COP.
- Debe ser responsive y verse muy bien en celular, tablet y computador.

ESTRUCTURA DE LA LANDING PAGE

1. HEADER / ENCABEZADO
- Logo o nombre de la tienda, por ejemplo: “TecnoMóvil Colombia”.
- Menú de navegación con enlaces a:
  - Inicio
  - Celulares
  - Promociones
  - Preguntas frecuentes
  - Contacto
  - Carrito
- Botón destacado tipo “Comprar ahora” o “Ver ofertas”.
- Ícono de carrito visible con contador de productos.

2. HERO SECTION / SECCIÓN PRINCIPAL
- Imagen principal atractiva con celulares modernos.
- Título poderoso de impacto, por ejemplo:
  “Los mejores celulares al mejor precio en Colombia”
- Subtítulo con propuesta de valor:
  “Encuentra smartphones de gama alta, media y económica con promociones exclusivas, pago seguro y envío rápido.”
- Botones CTA:
  - “Ver celulares”
  - “Aprovechar promociones”

3. SECCIÓN DE PRODUCTOS DESTACADOS
- Mostrar varias tarjetas de productos con imágenes reales de celulares.
- Cada tarjeta debe incluir:
  - Imagen real del celular
  - Nombre del equipo
  - Marca
  - Precio anterior tachado si tiene descuento
  - Precio actual en pesos colombianos
  - Porcentaje de descuento si aplica
  - Especificaciones cortas:
    - Almacenamiento
    - RAM
    - Cámara
    - Batería
    - Pantalla
  - Botón “Agregar al carrito”
  - Botón “Ver más”
- Incluir al menos entre 6 y 8 celulares diferentes.
- Usar ejemplos de marcas reconocidas como Samsung, Xiaomi, Motorola, iPhone, Honor o Realme.

4. SECCIÓN DE PROMOCIONES
- Crear una sección especial con ofertas llamativas.
- Ejemplos:
  - Descuentos por tiempo limitado
  - Envío gratis a toda Colombia
  - Accesorios gratis en compras seleccionadas
  - Cuotas sin interés
- Mostrar banners promocionales visuales y atractivos.
- Añadir un contador regresivo opcional para ofertas.

5. FILTROS O CATEGORÍAS
- Agregar accesos rápidos o filtros visuales por:
  - Gama alta
  - Gama media
  - Gama económica
  - Más vendidos
  - Nuevos ingresos
  - En promoción

6. CARRITO DE COMPRAS
- Debe existir un carrito funcional.
- El usuario debe poder:
  - Agregar productos
  - Ver cantidad
  - Aumentar o disminuir unidades
  - Eliminar productos
  - Ver subtotal
  - Ver total
- Mostrar resumen del pedido de forma clara.
- Incluir botón “Finalizar compra”.
- El carrito puede implementarse con almacenamiento local (localStorage) para conservar productos durante la sesión.

7. SECCIÓN DE BENEFICIOS O CONFIANZA
- Mostrar beneficios de comprar en la tienda:
  - Pago 100% seguro
  - Envíos rápidos
  - Garantía
  - Productos originales
  - Soporte por WhatsApp
- Usar iconos visuales modernos.

8. PREGUNTAS FRECUENTES
- Incluir una sección FAQ tipo acordeón.
- Preguntas sugeridas:
  - ¿Los celulares son nuevos y originales?
  - ¿Hacen envíos a toda Colombia?
  - ¿Qué métodos de pago aceptan?
  - ¿Los equipos tienen garantía?
  - ¿Puedo pagar a cuotas?
  - ¿Cuánto tarda el envío?
- Las respuestas deben ser claras y profesionales.

9. TESTIMONIOS
- Agregar testimonios de clientes ficticios pero realistas.
- Incluir nombre, ciudad y comentario breve.
- Ejemplo:
  - “Excelente servicio, mi celular llegó rápido y en perfecto estado.” – Laura, Bogotá
  - “Muy buenos precios y promociones, volveré a comprar.” – Andrés, Medellín

10. SECCIÓN DE CONTACTO
- Incluir:
  - WhatsApp
  - Correo electrónico
  - Dirección o cobertura nacional
  - Formulario de contacto corto
- Incluir botón de contacto rápido por WhatsApp.

11. FOOTER
- Enlaces rápidos
- Redes sociales
- Políticas de garantía
- Términos y condiciones
- Política de privacidad
- Derechos reservados

DISEÑO VISUAL
- Estilo moderno, premium y tecnológico.
- Buena jerarquía visual.
- Tipografía limpia y profesional.
- Botones llamativos.
- Uso de tarjetas con sombras suaves.
- Animaciones sutiles al pasar el mouse.
- Colores recomendados:
  - Fondo claro o degradado moderno
  - Azul, negro, blanco y acentos vibrantes
- La interfaz debe verse como una tienda tecnológica real y confiable.

FUNCIONALIDAD
- Responsive completo.
- Navegación suave entre secciones.
- Carrito funcional con JavaScript.
- Interacciones modernas.
- Código limpio y organizado.
- Optimización de carga.
- Estructura clara para fácil edición posterior.

CONTENIDO DE PRODUCTOS
Incluye productos de ejemplo realistas con nombres y precios en COP, por ejemplo:
- Samsung Galaxy A55 – $1.899.900 COP
- Xiaomi Redmi Note 13 – $1.149.900 COP
- iPhone 13 – $3.499.900 COP
- Motorola G84 – $1.299.900 COP
- Honor X8b – $1.199.900 COP
- Samsung Galaxy S24 – $4.299.900 COP

IMPORTANTE
- No uses texto genérico ni secciones vacías.
- Todo debe venir con contenido realista de ejemplo.
- Las imágenes deben ser reales o simuladas como si fuera una tienda auténtica.
- El resultado final debe sentirse listo para producción.
- Prioriza conversión, claridad y aspecto profesional.

ENTREGA
Genera el proyecto completo en un solo archivo HTML con CSS y JavaScript integrados, o separado en HTML, CSS y JS si eso permite mejor organización. El carrito debe funcionar.
```
