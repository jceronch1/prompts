# Chatbot para preguntar sobre un PDF

**Categoría:** [RAG y chat con documentos](README.md) · **Tecnologías:** Ollama (qwen3:8b), nomic-embed-text, SQLite

Chatbot en HTML, CSS y JS que vectoriza un PDF y responde solo sobre su contenido.

## Prompt

```text
Crear una app web de un Chatbot en  HTML, CSS y JS que se pueda subir o cargar un PDF y se pueda preguntar sobre ese documento únicamente y que se vectorice, ten en cuenta que tengo instalado Ollama en mi computador de Windows 11 y también tengo el modelo llm local qwen3:8b, además para los embeddings se debe usar el modelo nomic-embed-text:latest que también lo tengo instalado en mi computador.
Para la base de datos puedes usar sqlite
```
