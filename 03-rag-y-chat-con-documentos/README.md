# RAG y chat con documentos

Aplicaciones para conversar con PDFs y bases de conocimiento usando RAG y embeddings.

| Prompt | Descripción | Tecnologías |
| --- | --- | --- |
| [Cambiar la fuente de datos de una LLM Wiki (Karpathy)](llm-wiki-karpathy.md) | Ajusta una LLM Wiki basada en la propuesta de Andrej Karpathy para que lea los documentos desde otra carpeta. | LLM Wiki, Claude |
| [Chat con PDFs usando RAG-Anything](chat-pdfs-rag-anything.md) | App web en PHP para chatear con PDFs (con imágenes, tablas y figuras) organizados por categorías, con historial. | PHP, RAG-Anything, PostgreSQL + pgvector, Ollama, OpenAI, Gemini |
| [Chatbot para preguntar sobre un PDF](chatbot-pdf-ollama.md) | Chatbot en HTML, CSS y JS que vectoriza un PDF y responde solo sobre su contenido. | Ollama (qwen3:8b), nomic-embed-text, SQLite |
| [Clon de ChatPDF con citas](clon-chatpdf-con-citas.md) | App web tipo ChatPDF que muestra las citas de origen de cada respuesta y navega hasta ellas en el documento. | RAG, visor de PDF |
