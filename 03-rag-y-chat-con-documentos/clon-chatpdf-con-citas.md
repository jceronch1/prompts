# Clon de ChatPDF con citas

**Categoría:** [RAG y chat con documentos](README.md) · **Tecnologías:** RAG, visor de PDF

App web tipo ChatPDF que muestra las citas de origen de cada respuesta y navega hasta ellas en el documento.

## Prompt

```text
Crea una app web parecida a https://www.chatpdf.com/es para que se pueda subir un pdf y se le pueda realizar preguntas. Debe mostrar también las citas de los lugares donde se extrae la respuesta y si se le da clic en una cita que se vaya al lugar del PDF donde hable sobre ese tema. Ese lugar debe estar resaltado.
Pegar un pantallazo de chatpdf
```
