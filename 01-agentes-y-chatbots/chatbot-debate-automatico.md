# Chatbot de debate automático

**Categoría:** [Agentes y chatbots](README.md) · **Tecnologías:** Ollama (qwen3:8b), síntesis de voz

Debate automático entre dos personajes de IA con posturas opuestas y un moderador, cada uno con su propia voz.

## Prompt

```text
Crea un Chatbot automático de debate donde se van a preguntar dos supuestas personas.
1.	La primera es una persona científica y es atea. Se llama Judas
2.	La segunda persona es científica, pero es muy cristiana y religiosa. Se llama María
3.	Debe haber una tercera persona que es la que moderara el debate.
Para lo anterior se debe usar Ollama que esta instalado en mi PC con Windows 11 y tengo instalado varios modelos, para este caso usaremos el modelo qwen3:8b.

a partir de la app Crea un nuevo Chatbot automático de debate donde se van a preguntar dos supuestas personas.
1.	La primera es una persona científica y es atea. Se llama Judas que sea con la voz de hombre en español
2.	La segunda persona es científica, pero es muy cristiana y religiosa. Se llama María, que sea con la voz de mujer en español.
Para lo anterior se debe usar Ollama que esta instalado en mi PC con Windows 11 y tengo instalado varios modelos, para este caso usaremos el modelo qwen2.5:7b
El debate debe ser de respuestas cortas
se debe esperar a que acabe el audio para que se de respuesta y se responda con otro audio
```
