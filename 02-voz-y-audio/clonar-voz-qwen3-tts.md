# Clonar voz con Qwen3-TTS

**Categoría:** [Voz y audio](README.md) · **Tecnologías:** Qwen3-TTS, Python

App web para clonar voz a partir del modelo base Qwen3-TTS, ejecutable en CPU o GPU.

## Prompt

```text
Crea una app web para clonar voz partiendo de la información que esta en esta página web
https://huggingface.co/Qwen/Qwen3-TTS-12Hz-1.7B-Base
además, los archivos del modelo base ya están descargados y los puede ver en la carpeta modelo
Se debe poder ejecutar en una CPU o en una GPU RTX 4070 de 8GB o superior.
```
