# Navegar en la web con la mano

**Categoría:** [Visión por computador](README.md) · **Tecnologías:** Python, OpenCV, MediaPipe, PyAutoGUI

Control del navegador con gestos de la mano: scroll, clic, doble clic y clic derecho.

## Prompt

```text
Quiero crear un "Programa para navegar en la web con la mano" con Python en mi portátil. El objetivo: Una aplicación que usa mi cámara web para rastrear mi mano. Al colocar el dedo índice en la parte superior de la pantalla, esta se desplaza hacia arriba. Al colocarlo en la parte inferior, se desplaza hacia abajo. Requisitos técnicos: Utilice MediaPipe para el seguimiento manual y OpenCV para la cámara. Utilice PyAutoGUI para gestionar el desplazamiento real. Crucial: agregar una lógica de "tiempo de reutilización" o temporizador para que el desplazamiento sea rítmico y suave, no brusco o demasiado rápido. Dibuja líneas verdes/rojas en la pantalla para que sepa dónde están las zonas de desplazamiento. Permítame salir de la aplicación presionando 'q'. Instrucciones necesarias.
también debes crea las acciones de clic y doble click todo con la mano cuando una el pulgar con el índice seria click y si lo dejo presionado sea el doble click
y cuando abra toda la mano que sea como si hiciera click con el botón derecho del mouse.
```
