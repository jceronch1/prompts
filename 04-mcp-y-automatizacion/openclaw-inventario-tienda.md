# OpenClaw: inventario y reportes de una tienda

**Categoría:** [MCP y automatización](README.md) · **Tecnologías:** OpenClaw, SQLite

Automatización con OpenClaw: app de inventario, gráficas de ventas, alertas diarias de stock y resumen por audio.

## Prompt

```text
Crea una app web en la ruta c:\barato con base de datos SQLite con el nombre de “tiendax” para manejar el inventario de una tienda de abarrotes llamada “Barato”. Debes llenar datos ficticios e informar:
1.	Crea un logo para la tienda
2.	Crea un lema para la tienda de abarrotes
3.	Por medio de una gráfica que productos se venden más y cual menos
4.	Decirme que productos que ya están por agotarse o están en 0
5.	Crea una tarea diaria sobre los productos que están en stock mínimo. infórmame todos los días a las 7am
6.	Genera una grafica estadística donde demuestres cómo va la tienda referente a las ventas.
7.	Envíame un audio muy breve de como analizas la tienda a partir de sus ventas, me puedes decir si es rentable

Analiza la información de la base de datos tiendax y dime en un audio los tres productos que mas se venden.
```
