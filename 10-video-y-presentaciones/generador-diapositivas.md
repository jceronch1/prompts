# Generador de diapositivas estilo Gamma

**Categoría:** [Video y presentaciones](README.md) · **Tecnologías:** Google AI Studio, Gemini API, Nano Banana Pro

Programa para crear presentaciones a partir de un tema o un PDF, con imágenes generadas o buscadas en internet.

## Prompt

```text
En Google ai studio con una api de Gemini

Solo cuando genero un video con Veo3 y le doy exportar a PPTX me sale error, no me hace la presentación. Al exportar a HTML si me sale viendo con video.
Crea un programa llamado EDIKREAX para poder crear diapositivas estilo http://gamma.app/ donde se le dé un tema, o se le suba un archivo pdf y a partir de el muestre una estructura de las diapositivas que se va a crear con la posibilidad de modificarla. También tiene que darme la opción para poder escoger cuantas diapositivas va a crear.
Además las diapositivas deben tener dos formas de crearse con texto e imágenes:
1.	Una es utilizando NanoBanana Pro para completar la diapositiva con una imagen,
2.	La otra posibilidad es que busque usado la API de Google busque en internet una imagen que tenga que ver con cada una de las diapositivas.
Otras consideraciones
a.	Que el texto de las diapositivas sea en letras grandes
b.	Se debe poder exportar a PDF y a PPTX y HTML.
c.	Que se pueda Escuchar las diapositivas
d.	Que se pueda cambiar La imagen de cada diapositiva por otra imagen generara por nado banana o por búsqueda en la Web
e.	también que se pueda reemplazar la imagen de la diapositiva por un vide creado en Veo3
```
