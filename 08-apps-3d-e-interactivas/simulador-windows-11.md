# Simulador de Windows 11

**Categoría:** [Apps 3D e interactivas](README.md) · **Tecnologías:** HTML, CSS, JavaScript

Escritorio de Windows 11 funcional en el navegador: barra de tareas, menú inicio y ventanas.

## Prompt

```text
Actúa como un desarrollador senior experto en aplicaciones web interactivas, interfaces de escritorio, JavaScript, HTML, CSS y simulaciones realistas de sistemas operativos.

Quiero que crees un simulador funcional de Windows 11 que se ejecute directamente en el navegador, con una apariencia moderna, elegante y muy similar a la experiencia visual de Windows 11.

Objetivo
Desarrollar una interfaz tipo escritorio que simule Windows 11, incluyendo:
Barra de tareas centrada
Menú inicio
Ventanas arrastrables, minimizables y cerrables
Fondo de pantalla modernoIconos de escritorio
Diseño responsivo y fluido
Aplicaciones funcionales obligatorias
El simulador debe incluir por lo menos estas 3 aplicaciones completamente funcionales:
Paint
Lienzo para dibujar con el mouse
Selección de color
Cambio de grosor del pincel
Opción de borrar
Botón para limpiar el lienzo
Notepad
Área de texto editable
Crear, escribir y borrar texto
Opción de simular “guardar” contenido en memoria local del navegador
Interfaz sencilla al estilo bloc de notas
Calculadora
Operaciones básicas: suma, resta, multiplicación y división
Interfaz visual parecida a una calculadora de escritorio
Botones funcionales y pantalla de resultados
Requisitos técnicos
Usar HTML, CSS y JavaScript
Todo en un solo archivo o en archivos claramente organizados
No usar frameworks pesados, salvo que sea estrictamente necesario
Debe funcionar abriendo el proyecto en navegador
Código limpio, bien estructurado y comentado
Buena experiencia visual y de usuario
Extras deseables
Animaciones suaves al abrir y cerrar ventanas
Reloj en la barra de tareas
Efecto de enfoque/desenfoque en ventanas
Sonidos sutiles del sistema
Modo oscuro estilo Windows 11

Entrega esperada
Entrega el código completo y funcional, listo para ejecutar, con un diseño atractivo y una experiencia lo más cercana posible a un mini Windows 11 dentro del navegador.
```
